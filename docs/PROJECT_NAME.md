# PikoNest — название проекта

Решение владельца от **2026-10-04**: проект и репозиторий называются **PikoNest**
(ранее **PIKOOS**). Каноническое написание — PikoNest.
Репозиторий: [EriArk/PikoNest](https://github.com/EriArk/PikoNest).

Этот шаг обновляет название репозитория, README и документацию. История Git,
видимость репозитория и продуктовые требования сохраняются. Скриншоты и журналы
проверок остаются оригинальными: на них может быть прежнее название. Подписи
установленных APK и профилей сторонних лаунчеров в инструкциях отражают их
фактические текущие имена.

## Следующий шаг переименования

Владелец подтвердил, что технические идентификаторы тоже нужно обновить позже.
До отдельной миграции сохраняются:

- Android package/application IDs и Java packages `art.pikoos.*`;
- `.pikoos/`, пути пользовательских данных и имена локальных артефактов;
- идентификаторы интеграций, intent actions/extras и зарегистрированные URI;
- существующие метки APK и профили внешних лаунчеров.

Миграцию нужно выполнить согласованно: инвентаризировать идентификаторы и точки
интеграции, обеспечить перенос или совместимое чтение проектов, библиотеки,
настроек и восстановления сеанса, затем проверить обновление существующей
установки и запуск из сторонних лаунчеров. Замена application ID сама по себе
создаёт отдельное Android-приложение и не переносит его приватные данные.
Не выполнять глобальную замену технических строк вместо такого перехода.

Переименование не меняет формат стандартного картриджа: `.p8` и обычный PICO-8
остаются основой проекта. Выпуск APK по-прежнему требует окончательной приёмки
владельцем.
