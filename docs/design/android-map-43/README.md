# Android 0.0.43 — карта из своих тайлов

2026-10-04, база `39798a6`. Ограниченный G03.1: общий редактор карты и обычный
`map()` соединяют ресурсы с игровым полем. Герой, жанровый шаблон и отдельный
PikoNest runtime API не нужны. G03/G04/M2 и физическая UX-приёмка не закрыты.

## Пользовательский путь

- Четвёртый инструмент «Карта», переключение L/R или касанием вкладки.
- Крестовина двигает курсор по 128×64, окно 16×16 клеток следует за курсором.
  Движение и касание карты не рисуют; A ставит выбранный тайл.
- X открывает весь лист из 256 тайлов 8×8. Крестовина/касание выбирают,
  A подтверждает, B отменяет. Пока открыт выбор, Start/Undo/смена инструмента
  не запускают и не меняют проект. Тайлу 0 соответствует пустая клетка.
- Y отменяет клетку, R2 возвращает; возврат также доступен через меню истории.
  Повторное размещение того же тайла не создаёт запись. Состояние публикуется
  только после успешной записи файла. История пока ограничена текущим сеансом.
- Курсор и выбранный тайл сохраняются отдельно для каждого проекта.
  Незавершённый выбор тайла при пересоздании приложения отменяется.
- Для изображения в игре: в коде выбрать строку внутри `_draw` после `cls`,
  X → «map · показать карту» → параметры → «Вставить в черновик» → Start.
  Размер — в клетках; положение на экране — в пикселях. Вставка отменяется целиком.
  Существующий шестипараметрический вызов открывается через L → поля строки.

## Совместимость и память

Сверено с [официальным руководством PICO-8](https://www.lexaloffle.com/dl/docs/pico-8_manual.html#Map):
обычная карта имеет 128×32 независимых клеток и ещё 128×32 в общей памяти нижней
половины gfx. Клетка хранит байт номера спрайта. Верхняя половина сериализуется
в `__map__`, два hex-символа на клетку; нижняя читается из `__gfx__`.

Редактор **пишет только строки 0–31**. Строки 32–63 видны, помечены «Только просмотр»;
попытка записи объясняет общую память и не меняет файл. Это граница первого
инструмента, а не ограничение PICO-8. Нижние спрайты можно выбирать как тайлы:
сам выбор/размещение ссылки в верхней карте их пиксели не меняет.

`P8Map` сохраняет несвязанные секции, существующие окончания строк, регистр
неизменённых hex-цифр и отсутствие финального перевода строки. При необходимости
дополняет только недостающие строки карты. Поддерживает полные строки по 128 байт,
LF/CRLF; дубликаты, неполные/лишние строки и некорректные цифры отклоняет до записи.
Разбор карты отложен: такой cart остаётся доступен в редакторе кода.

Изолированная [техническая проба](memory-probe.p8), не пользовательский проект,
запущена headless официальным PICO-8 0.2.7: `mget(0,0)=171`, `mget(0,32)=171`,
`mget(127,63)=205`; после `mset(0,32,18)` пиксели gfx равны 2 и 1.
При ненулевом спрайте 0 пустая клетка через `map()` оставила цвет фона 1.
[Вывод runtime](memory-probe.txt). Проба использует отдельные work/home/tmp,
не перезаписывает проекты или купленный runtime.

## Проверки на Retroid

Host 0.0.43 / code 43, Runtime Test 8, официальный пользовательский PICO-8 0.2.7.
Полный `experiments/android-host/build.ps1` пройден; `MapWorkflowTest` — 47 проверок:
границы, shared nibble order, точечные байты, CRLF/LF/no-EOL, неподдержанные секции,
неудачная запись, no-op, история, выбор/отмена, запуск и обычные параметры Lua.

Через обычный UI с контроллерными событиями ADB:

1. Создан новый blank `blank-0006` / «Чистый лист 6».
2. Пиксельной кистью нарисованы трава и цветок в тайлах 1 и 17.
3. Собрано поле 12×10 с шестью цветами; проверены Undo/Redo клетки.
4. После force-stop карта, курсор и тайл восстановлены; cart не изменился.
5. Через каталог вставлен `map(0,0,0,0,16,16)`, Undo/Redo вставки, Test и возврат.
6. Все **16384** центров пикселей официального игрового экрана совпали
   с ожидаемыми цветами из сохранённых gfx/map: [проверка](runtime-pixels.json).
7. Проверены компактный 720×960 и родной 1240×1080, форма существующего вызова,
   выбор тайла/Cancel, просмотр общей половины и отказ записи в неё.
   Касание карты и отмена выбора тайла не изменили cart.
8. Все **25** прежних файлов проектов/библиотеки сохранились побайтно; добавлен
   один cart. [Хеши](preservation.json). Gfx и map до/после вставки Lua одинаковы.

Физические кнопки пользователь в этом прогоне не проверял. ADB не заменяет
оценку удобства в руках. Размер экрана восстановлен, media volume 0.
APK Release/prerelease не публиковался. APK 287652 bytes, SHA-256:
`8e5493709c61efdba157c61c00475d9faeacea51ba3d7218917d1e1f9456121f`.
[Итоговый cart](field.p8), SHA-256:
`c1112b6f1e083bc05ad4b08a0162148284c18ec389c28e6ee94251add6219e42`.
