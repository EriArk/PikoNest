# Android 0.0.41 — читаемый пиксельный текст

2026-10-04, база `38936a9`. По просьбе владельца приоритет этого среза —
читаемость с сохранением пиксельной стилистики. G04.1 остаётся следующим
функциональным шагом; новые инструменты размещения спрайтов здесь не добавлены.

## Изменения

- Tiny5 в шести поверхностях host заменён на Monocraft. Минимальный размер
  текста — 18 логических единиц вместо прежних 14–17 в мелких подписях.
  Крупные заголовки сохраняют размеры. Палитра и пиксельная отрисовка сохранены.
- Общий `PixelText` задаёт одинаковые метрики для измерения и рисования.
  Для действий используются 20 единиц, либо 18 при тесной кнопке.
- Лигатуры отключены: `>=`, `!=` и другие операторы Lua видны буквально.
  Шаг курсора, выделения, горизонтальной прокрутки и touch-ячеек теперь
  вычисляется из ширины шрифта, вместо прежнего фиксированного шага 12.
- На компактных экранах сокращены подписи действий и подсказки, исправлены
  пересечения в шапке/подвале проектов. Основные действия сохраняют названия.
- Runtime Test 8 использует тот же шрифт в меню игры. Обработка ввода,
  запуск, остановка и протокол возврата не менялись.

## Шрифт и лицензия

[Monocraft, Idrees Hassan](https://github.com/IdreesInc/Monocraft), SIL OFL 1.1.
Неизменённый `dist/Monocraft-ttf/Monocraft.ttf` взят из ревизии
`e498bf70aeb25b4bdcff1e44d878fb2cb4f7c2a9`; совпадение с закреплённым файлом проверено.
SHA-256: `262e31822e0a75be567b02320bfa092143d871e8a273e529d1c5ab0c04cd215f`.
Файл и полный copyright/license хранятся в `experiments/android-host/assets/`
и входят в обе локальные APK. Tiny5 сохранён как прежний ресурс, но не выбран для UI.

Перед выбором сравнены Tiny5, Monocraft, Pixelify Sans, Press Start 2P и DotGothic16.
У проверенного Pixelify отсутствовали кириллические О/П, Press Start был слишком
широким, DotGothic16 — слишком тонким для нужного характера интерфейса.
У Monocraft проверено покрытие русских букв, цифр, Lua-операторов и стрелок.
Символ меню `≡` использует Android fallback; текст кириллицы — сам Monocraft.

## Проверки

- Полная сборка host с существующими portable regression-тестами прошла.
  Новые тесты, повторяющие реализацию рисования, не добавлялись.
- Сборка runtime прошла; все 262 размера и хеша sparse payload совпали.
- Обе APK установлены на Retroid Pocket Classic / Android 14.
- Просмотрены формы, код и курсор, Play, полка проектов, папки, подключение
  runtime, меню игры. Проверены native 1240×1080 и компактный 720×960 viewport.
- Контроллерными событиями ADB выполнены переходы, открытие/отмена формы,
  движение курсора, Test существующего cart официальным PICO-8 0.2.7,
  Continue и выход обратно в мастерскую. Это не новая физическая UX-приёмка.
- Все **24** прежних файла проектов и библиотеки сохранены побайтно:
  [хеши до/после](preservation.json). Новых cart не создавалось.
- Размер экрана возвращён к физическому, media volume = 0.
