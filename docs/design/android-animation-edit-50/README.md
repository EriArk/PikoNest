# Android 0.0.50 — повторная правка анимации

2026-10-04, база `20b34a6`. Ограниченный **N01.2**: уже вставленную анимацию
можно открыть из кода, изменить кадры/порядок/время/повтор/положение, сравнить
исходный и предложенный Lua и заменить только выбранный блок одной правкой.
Формат игры и генератор анимации 0.0.49 не менялись.

## Путь с контроллера

Код → A редактировать → курсор на **любой строке известного блока анимации** →
**L «поля»** (либо Select → «Поля текущей строки»). Открывается прежний инструмент
кадров с заголовком «Анимация · правка» и диапазоном строк заменяемого блока.
Доступны все поля, области листа, просмотр, копирование/удаление и перестановка
кадров из N01.1. Ничего не вставляется повторно при открытии формы.

«Просмотреть Lua» открывает **«будет»**. X переключает **«было / будет»**, ↑↓ читают
строки, ←→/L/R листают. A в «было» сначала возвращает к «будет»; только A в «будет»
применяет замену. B возвращает к полям, B из полей отменяет предложение полностью.
Start не применяет незавершённую форму. На touch переключатель расположен под
заголовком просмотра. Изменения сначала попадают в Lua-черновик, затем сохраняются
обычным способом или через Test.

Одна отмена возвращает весь прежний блок и положение курсора. Повтор — весь новый.
Если параметры не изменились, применение не переписывает текст и не добавляет
пустую запись в историю. Незавершённая правка, выбор «было/будет» и позиция чтения
восстанавливаются после перезапуска. В журнале сохраняются отдельно исходная
привязка к блоку и изменённые поля; версии прежних журналов остаются читаемыми.

## Безопасное распознавание

`AnimationEdit` работает в переносимом core. Комментарий `-- animation: ...`
служит только местом поиска. Проверяются **весь блок**, таблица, времена, вызовы,
цикл и границы `do/end`, затем результат сравнивается с обычным генератором Lua.
Совпадения внутри строк и длинных комментариев игнорируются. Два одинаковых
соседних блока остаются разными целями: выбирается содержащий курсор диапазон.

Поддерживается точная форма блока N01.1 с единым внешним отступом и LF/CRLF/CR;
наличие или отсутствие последнего перевода строки сохраняется. Времена из точных
16.16 границ восстанавливаются в исходные миллисекунды, включая шаги по 50 мс.
Перед заменой повторно сравниваются исходные байты целевого диапазона. Lua вне
него и остальные секции `.p8` не нормализуются. Метаданные PikoNest игре не нужны.

Если изменена логика, добавлен комментарий/оператор внутри блока, переименованы
локальные переменные, используются выражения вместо поддержанных констант,
нарушена известная структура или параметры вышли за пределы формы, визуальная
правка отказывается от замены. Обычный Lua-редактор остаётся доступен. Это граница
распознавания PikoNest, а не требование или ограничение языка PICO-8.
Ручные изменения поддержанных чисел допустимы, если весь блок по-прежнему точно
соответствует форме. Удалённый/изменённый маркер не даёт оснований угадывать блок.

Includes, изменённое окружение и переопределённые `time/sspr` по-прежнему дают
консервативный отказ. Это не общий Lua-парсер и не восстановление произвольных
анимаций чужой игры. Отражение, события/сброс, состояния, библиотека анимаций и
нагрузка нескольких последовательностей остаются открытыми частями N01/B03.

## Проверено

- Полный `build.ps1` прошёл, включая **156 новых проверок AnimationEditTest**:
  диапазоны/одинаковые соседи, три окончания строк и отступы, EOF, отсутствие
  изменений, дробные времена/32 кадра, отказ ручной логики/конфликтов, stale target,
  восстановление, повреждённый журнал, Undo/Redo, контроллерное сравнение,
  блокировка Start, ошибка записи/повтор и сохранность неизвестной секции.
  Во время подготовки исправлены два ожидания самого теста: отсутствие маркера
  означает отсутствие привязки, а повреждение журнала должно действительно менять
  байт. После исправлений выполнены целевой тест и итоговая полная сборка.
- Через UI создана **«Копия 17» (`remix-0017`)** из готовой анимации. Кадры
  переставлены; теперь (8,7,8,9) длится 750 мс, затем (8,8,8,8) — 500 мс.
  Положение изменено с (56,8) на (72,8), повтор по кругу сохранён.
- Force-stop восстановил форму в «было», Start не применил её. Проверены родной
  1240×1080 и компактный 720×960 экраны, подтверждение «будет», Save → Undo/Redo
  с побайтным восстановлением и повторное открытие сохранённого результата.
- Через обычную контроллерную клавиатуру в черновике `time()` изменён на `time()+1`.
  [Форма отказалась](manual-refused.png) его заменять. Ручной эксперимент отменён,
  сохранённый cart остался побайтно прежним.
- [Итоговый cart](tested.p8) проверен официальным пользовательским PICO-8 0.2.7
  на Retroid / Runtime Test 8. В серии семи снимков оба кадра совпали с пикселями
  листа на новом месте, а прежнее место осталось фоном: дубликат не создан.
  [Кадр 1](game-0.png), [кадр 2](game-2.png), [сопоставление](runtime-frame-match.json).
  Прежний oracle времени N01.1 не запускался повторно: генератор не менялся.
- **32 прежних файла** проектов/библиотеки сохранены побайтно. В копии заменён
  ровно один блок; Lua снаружи и все ресурсные/неизвестные секции прежние.
