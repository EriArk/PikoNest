# Android 0.0.44 — прямоугольник и заливка карты

2026-10-04, база `4e8d2b9`. Ограниченный G03.2, общий для blank/imported/template
картриджей без обязательного героя. Камера и переходы комнат остаются N02/M05.

## Управление и сохранение

В «Карте» L2 либо Select → «Инструменты карты» открывают кисть, прямоугольник,
заливку. Выбор также доступен касанием. X по-прежнему выбирает тайл.

- Кисть сохраняет одну клетку по A.
- Прямоугольник: A ставит первый угол, крестовина/касание выбирают второй,
  следующий A открывает обзор, ещё A подтверждает всю правку.
- Заливка: A показывает связанную область клеток с тем же **номером тайла**,
  следующий A сохраняет. Соседство по четырём сторонам; диагонали не соединяются.
- Розовая граница и счётчик показывают только реально меняющиеся клетки.
  В обзоре крестовина/касание перемещают точку просмотра, не меняя предложение.
  Это позволяет осмотреть область больше окна 16×16.
- B из обзора прямоугольника возвращает ко второму углу; ещё B отменяет.
  B из заливки отменяет. Y отменяет любое незавершённое предложение целиком.
  После применения Y отменяет сохранённую операцию целиком, R2 возвращает.
- Пока предложение открыто, Start, смена инструмента/тайла, меню и Redo не обходят
  подтверждение. Неизменяющее предложение закрывается без записи и новой истории.

Данные пишутся одной операцией `P8Map.withTiles`, а не последовательностью
поклеточных сохранений. Ошибка записи оставляет предложение, cart и историю
доступными для повторной попытки. Undo/Redo после применения пока живут в сеансе.

Черновик хранит инструмент, оба угла/начало заливки, тайл, фазу, точку обзора и
SHA-256 исходного cart. Перезапуск восстанавливает предложение только для тех же
байтов. Изменённый исходник или некорректное состояние дают понятную ошибку до
записи. Выбор инструмента/тайла без начатой операции после перезапуска отменяется.

## Границы PICO-8

Сверены [Map / MGET / MSET официального руководства 0.2.7](https://www.lexaloffle.com/dl/docs/pico-8_manual.html#Map).
Карта по-прежнему обычная `__map__`, без нового формата или runtime API.
Инструменты меняют только верхние 128×32 клетки; заливка ограничена этой областью,
даже если за строкой 31 находятся те же номера в общей gfx/map-памяти.
Выбор инструментов явно показывает границу 0–31. Общая половина остаётся для чтения.
Нижние спрайты допустимы как ссылки-тайлы; их данные при правке карты не меняются.
Остальные ограничения формата — как в [0.0.43](../android-map-43/README.md).

Прямоугольник включает обе крайние клетки и заполняется одним тайлом.
Заливка сравнивает номера, не похожесть пикселей или флаги. Тайлом 0 можно стереть
область. Это поведение инструментов PikoNest, не новая семантика Lua-функций PICO-8.

## Проверки

Полный `experiments/android-host/build.ps1` пройден. `MapToolsTest` — 12336 проверок
(включая перебор неизменённых клеток), `MapWorkflowTest` — 47 прежних проверок.
Проверены обратные углы, no-op, диагонали/границы строк, заливка 4096 клеток,
защита shared gfx/map, несвязанные секции, отказ записи, история, восстановление
обеих фаз/заливки, несовпавший источник, модальные команды и обзор без изменения
геометрии. Ядро компилируется JDK без Android.

На Retroid Pocket Classic, Android 14, host 0.0.44 / runtime Test 8:

1. Через UI создана «Копия 11» (`remix-0011`) из сохранённой «Чистый лист 6».
   [Исходная копия](baseline.p8) побайтно равна исходному проекту.
2. Через L2 выбран прямоугольник тайлом 17: (3,10)–(6,11), **8** клеток.
   До Confirm файл неизменён. Force-stop → восстановление обзора; Start/R/Menu
   не применили его. Confirm → Undo вернул исходные байты, Redo вернул все 8.
3. Через Select → инструменты выбрана заливка тайлом 0. Область содержит **9**
   клеток: прямоугольник и примыкающий цветок в (7,10). Смена размера экрана
   восстановила предложение; Confirm → Undo/Redo проверены побайтно.
4. [Итоговый cart](filled.p8) запущен официальным пользовательским PICO-8 0.2.7.
   Все **16384** центров пикселей совпали с ожидаемыми gfx/map; Lua/gfx и другие
   секции неизменны. [Клетки и сверка изображения](verification.json).
5. В финальном UI проверено обратное предложение заливки цветами той же пустой
   области: обзор/переход к другой части карты и Cancel не меняют итоговый файл.
   Также проверены касание второго угла и отмена без записи.
6. Все **26** прежних файлов проектов/библиотеки побайтно сохранны; добавлена одна
   копия. [Хеши](preservation.json). Экран восстановлен, media volume 0.

Проверки управления выполнялись событиями ADB и касаниями; физическую эргономику
владелец в этом прогоне не подтверждал. Родительские G03/M2 не закрыты.
