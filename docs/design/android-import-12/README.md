# Android 0.0.13 — один внешний .p8 в мастерской

Проверено 2026-10-03 на Retroid Pocket Classic, serial `DEVICE_SERIAL`.
Это экспериментальный срез импорта, не завершённый визард или браузер игр.

## Сценарий

«Мои игры» → Down → Down → A → системный выбор `.p8` → предпросмотр → A.
Создаётся отдельный проект с именем выбранного файла; оригинал остаётся на месте.
B отменяет предпросмотр без создания проекта. Start в предпросмотре не запускает
игру. После открытия доступны существующие общие инструменты, библиотека и Start.
Источник спрайта подписывается именем проекта; внутренний UUID в подписи не нужен.

Выбор файла использует [Android SAF](https://developer.android.com/training/data-storage/shared/documents-files).
Запрашивается чтение, URI не открывается на запись и не становится зависимостью
проекта. Чтение провайдера происходит вне UI-потока с бюджетом 2 МиБ. Это бюджет
эксперимента, не ограничение формата PICO-8. Поздний результат отменённого чтения
игнорируется. Если процесс/Activity уничтожен во время незавершённого чтения,
нужно выбрать файл ещё раз. Уже готовый предпросмотр сохраняется атомарно.

Обычные `.p8`, `.p8.png` и внешние `#include` различаются согласно
[официальному руководству PICO-8](https://www.lexaloffle.com/dl/docs/pico-8_manual.html).
Здесь поддержан один текстовый `.p8`. PNG, архивы, соседние файлы, includes и
мультикартриджные наборы не импортируются автоматически; предпросмотр предупреждает
о границе переноса. Чтение редактором не проверяет Lua и не доказывает совместимость.
Неизвестные секции и код сохраняются байт в байт. Неподдерживаемые редактором данные
отклоняются без записи исходника и без создания заменяющего шаблона.

## Проверки

- `build.ps1` прошёл все прежние проверки: LabCartridge PASS, Workshop 799,
  SpriteWorkflow 2807, LibraryWorkflow 28, DrawingWorkflow 4269,
  RegionWorkflow 16422, HeroBinding 42, HeroFree 100, CopyWorkflow 49230,
  AssetLibrary 49207, AssetNaming 53.
- Новый `CartridgeImportTest`: 29 проверок. Байт-сохранность CRLF/неизвестных
  данных, запись/чтение черновика, имена и безопасный ID, неподдерживаемые типы,
  граница бюджета чтения, испорченные записи, управление кнопками, отмена,
  запрет запуска в предпросмотре, ошибки публикации/очистки/открытия, повтор без
  дубликата, конфликт с изменённым проектом, сохранность внешних ссылок.
- Android APK собран и установлен через `install -r`, без очистки данных.
  Финальный APK: versionCode 13, versionName 0.0.13,
  SHA256 `12ff032ad0ab884bef4073a208e7812aa799c377ac52f588a0087eb865176339`.
- Собственный `assets/lights.p8` скопирован в Download как
  `pikoos-import-lights.p8`, затем выбран через реальный Android picker.
  Источник и импортированный `game.p8` имеют одинаковый SHA256
  `99a38a85fa19403c715e61ddee8c68ec19db269cfbeee0a3a9c75308eb258903`.
- Предпросмотр восстановился после Home → завершение фонового процесса →
  холодный запуск. Отсутствие PID проверено. Start ничего не создал; B оставил
  прежние семь проектов и пустой атомарный файл черновика.
- Повторный выбор и A создали ровно один проект
  `import-fef356d5-f8ba-4482-8f4a-a00bbc0ff0a6` с точной копией исходника.
  Имя хранится отдельно в `.pikoos/import-name`, сам `game.p8` не зависит от него.
- Импортированная игра запущена официальным пользовательским PICO-8 через
  текущий внешний backend. Пазл решён за два хода: `ALL AGLOW!`. Выход Ctrl+Q
  вернул мастерскую. Это проверка данного файла, не общий сертификат импортера.
- Из импортированного проекта выбраны пиксели 16×16 в (0,0); контроллерной сеткой
  введено имя «Огонёк», затем явно сохранена независимая запись
  `78bb5e93-0e4a-42dd-adff-16f264560644.pksp`. Считанная с устройства запись
  сопоставлена с portable `SpriteAsset.capture`: пиксели, имя, источник,
  SHA256 и координаты совпали. В библиотеке три записи.
- После извлечения совпали все семь исходных контрольных сумм проектов
  (Moon Garden, blank-0001, garden-0001, puzzle-0001, remix-0001..0003).
  Импортированная копия и файл в Download также сохранили исходный хеш.
- Контрольный собственный `.txt` отклонён с сообщением о текстовом `.p8`;
  новых проектов не появилось. Файл не был удалён или изменён.

## Осталось

События кнопок поданы через ADB, это не физическая пользовательская приёмка.
Системный picker на Retroid позволил выбрать файл кнопками, но для открытия
панели корней и смены папки использовались касания. Полный сценарий без касаний
не подтверждён. Внутри мастерской импорт, отмена, сохранение и ввод имени
проверены семантическими действиями контроллера. Системный экран пока имеет
Android-стиль; собственный браузер выбранных папок должен закрыть эту границу.

Хранилище проектов/библиотеки пока внутри приложения. Выбор папок, экспорт
проектов, `.p8.png`/Splore, зависимости, полноценное редактирование Lua и другие
типы ресурсов ещё не готовы. Реальный сбой накопителя/облачный провайдер на
устройстве не имитировались; отказы портов проверены в portable tests.
