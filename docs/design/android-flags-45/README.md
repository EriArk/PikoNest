# Android 0.0.45 — стандартные флаги тайлов

2026-10-04, база `0e36508`. Ограниченный G03.3, общий для blank/imported/template
картриджей. Никакого обязательного героя или нового runtime API.

## Пользовательский путь

В «Карте» X выбирает тайл. L2 либо Select → «Инструменты карты» → «Флаги тайла»
открывают восемь битов **выбранной кисти**, не клетки под курсором.
Миниатюра и номер показывают, какой ресурс меняется. Подсказка объясняет,
что флаги относятся ко всем клеткам с этим тайлом, а смысл задаёт Lua игры.

- Крестовина выбирает бит 0–7 в двух рядах, A переключает его в черновике.
- Под битами показано соответствующее выражение `fget` и будущее значение.
- Вниз из второго ряда переводит на «Сохранить», A применяет все изменения.
- B или Y отменяет предложение; касания позволяют переключить бит и сохранить.
- Start/меню/смена инструмента/Redo не обходят явное сохранение.
- После сохранения Y отменяет всю правку, R2 возвращает её. История пока сеансовая.

Черновик переживает перезапуск host и смену размера экрана. Он привязан к SHA-256
исходного cart: внешняя правка или некорректное состояние отклоняются до записи.
Ошибка сохранения оставляет предложение для повторной попытки; no-op не создаёт
новой истории и не добавляет пустую секцию.

## Формат и границы

Сверены [официальные FGET/FSET и MAP](https://www.lexaloffle.com/dl/docs/pico-8_manual.html).
У каждого из 256 спрайтов есть восемь флагов 0–7 без предопределённого назначения.
`fget(n)` возвращает маску, `fget(n,f)` — состояние бита; `map` умеет отбирать тайлы
по маске. Флаг сам по себе не включает коллизию, дверь или иной игровой эффект.

Переносимый `P8Flags` читает/пишет обычный `__gff__`, отдельно от gfx/map.
Флаги нижних спрайтов 128–255 можно менять без записи общей gfx/map-памяти.
Поддержаны отсутствующая секция и до двух полных строк по 256 hex-символов.
При реальном изменении недостающие строки заполняются нулями; пустые значения
читаются как 0. Сохраняются LF/CRLF, отсутствие конечного перевода строки,
нетронутые hex-символы и несвязанные секции. Меняются только нужные полубайты.

Короткие/слишком длинные/повреждённые строки и дубли секции этим адаптером
отклоняются без записи. Короткая строка не объявляется несовместимой с PICO-8:
это ограничение первого редактора PikoNest. Чтение флагов ленивое, поэтому оно
не блокирует открытие/редактирование Lua такого cart.

Прямой вход из произвольной области редактора спрайтов, пакетная правка флагов
нескольких тайлов, UI слоёв карты, коллизии, камера и переходы ещё не реализованы.

## Проверки

Полная сборка `experiments/android-host/build.ps1` прошла вместе со всеми прежними
проверками. Новый `FlagsTest` — 10443 проверки, включая перебор несвязанных флагов:
оба ряда, все биты, диапазоны, no-op, сохранение секций/регистра/EOL, ошибки
формата/записи, controller workflow, модальность, восстановление, конфликт
исходника и единая отмена. Ядро компилируется JDK без Android.

На Retroid Pocket Classic / Android 14, host 0.0.45, runtime Test 8:

1. Через UI создана «Копия 12» (`remix-0012`) из «Копия 11».
   [Исходный cart](baseline.p8) сохранён без изменения оригинала.
2. Для тайла 17 включены 0 и 7 (129). До Save файл прежний; Start/R/Menu/X/Redo
   не применили предложение. Force-stop/restart восстановил выбранный бит.
   Save → Undo восстановил исходные байты, Redo вернул те же флаги.
3. Через выбор тайла 255 включён бит 6 (64). Проверены оба ряда `__gff__`.
   [Результат](flags.p8): кроме этих двух байтов, все флаги нулевые;
   все исходные секции сохранены побайтно.
4. Проверены компактные 720×960 и родные 1240×1080, восстановление формы,
   touch-переключение с последующей отменой без записи.
5. Через контроллерный каталог вставок в Lua добавлены два `print(fget(...))`.
   [Итоговый проект](tested.p8) запущен официальным пользовательским PICO-8 0.2.7:
   на экране 129 и 64. Select → выход возвращает в мастерскую.
6. После выхода отдельная headless-проба в официальном runtime использовала
   копию тех же данных и [собственный проверочный Lua](runtime-probe.p8).
   [Вывод](runtime-probe.txt): правильные восемь битов тайла 17 и `map(...,128)` —
   отмеченный цветок рисуется, неотмеченная трава пропускается. Exit code 0.
   Это подтверждение флагов/фильтра карты, не готовая механика коллизий.
7. Все **27** прежних файлов проектов/библиотеки сохранены, добавлен один проект.
   [Хеши](preservation.json), [сверка секций](verification.json).
   В конце родной размер экрана восстановлен, media volume 0, черновик закрыт.

Управление проверялось событиями ADB и касаниями. Физическая эргономика и
пользовательская приёмка остаются открытыми; G03/M2 целиком не закрыты.
