# Android lab 0.0.52 — N02.2: камера по комнатам

2026-10-04. Ограниченный срез N02; сцены и события переходов M05 ещё впереди.

## Путь пользователя

В любом проекте: **Код → A → X → Камера · комнаты**. Задаются X/Y точки мира
и число комнат по горизонтали/вертикали. Каждая комната — один экран 128×128.
Герой и жанровый шаблон не требуются; точку можно выбрать из имён проекта.

На существующей известной камере **L** открывает параметры. **Y** переключает
«Следить / Комнаты», сохраняя точку и размеры мира. Затем «Просмотреть Lua»
показывает полное сравнение; только A применяет замену одной отменяемой правкой.
B возвращает к полям, Start не применяет предложение и не запускает игру.
Вызов заменяется на месте; вторая камера не добавляется. Если размеры follow
не кратны 16 клеткам, переключение отклоняется без изменения размеров/исходника.

## Обычный PICO-8 и границы инструмента

Формула для сетки 2×2:

```lua
camera(flr(mid(0,(x),2*128-1)/128)*128,flr(mid(0,(y),2*128-1)/128)*128)
-- рисование мира
camera()
-- экранные счёт, меню и подсказки
```

Сверено [официальное руководство camera / mid / flr](https://www.lexaloffle.com/dl/docs/pico-8_manual.html).
Мир начинается в (0,0). Камера стоит на начале текущей комнаты и переключается
при пересечении 128, 256… За краем сетки остаётся ближайшая комната. Координаты
объектов не меняются. Ограничение выполняется до деления, в том числе для крайних
чисел 16.16; каждое выражение точки вычисляется один раз на вызов.

Форма предлагает 1..8 × 1..4 комнаты — стандартные размеры карты, **не предел
мира PICO-8**. Произвольные размеры комнат/начала мира, плавность, двери/области,
перенос объектов, загрузка карт и состояние отдельных сцен пока не реализованы.
Комнаты здесь — участки общего поля, а не отдельные загружаемые сцены. Автор
сам выбирает место камеры и reset перед HUD; автоматического размещения нет.

Точные известные формулы открываются повторно. Ручная неизвестная формула
остаётся обычной формой X/Y без нормализации. Переопределённые API, includes и
изменённое окружение проверяются консервативно до записи. При смене режима
проверяются и новые зависимости (`flr` либо `max`). Полную семантику Lua проверяет
официальный runtime. `.pikoos` и API PikoNest игре не нужны.

## Проверки

- Полная сборка прошла, включая **69 новых проверок RoomCameraTest**: вставка,
  LF/CRLF/CR, отображение четырёх полей, повторная правка/no-op, смена режима,
  сохранение префиксов/комментариев, конфликты API, восстановление предложения,
  границы выражений, контроллерный путь, ошибка записи/повтор и Undo/Redo.
- Тест восстановления обнаружил различие с обычным применением: исходная
  привязка читала изменяемую выбранную форму. Теперь исходный тип сохраняется
  отдельно, и обычное применение/восстановление дают один результат.
- [Проверочный cart](runtime-check.p8) в пользовательском **PICO-8 0.2.7**:
  **18/18** ([экран](runtime-check.png)). Проверены точные/дробные границы,
  отрицательные/крайние координаты, 1×1 и 8×4, вычисление точки один раз,
  перенос рисования, неподвижный HUD и замена предыдущей камеры.
- На Retroid из копии 18 создана **«Копия 19» (`remix-0019`)**. Через UI follow
  заменён комнатами 2×2. В [готовом примере](tested.p8) отличается ровно один
  вызов камеры относительно [исходника](baseline.p8); остальные Lua/данные целы.
- Force-stop восстановил то же сравнение. Start оставил предложение открытым.
  На экранах 1240×1080 и 720×960 проверены поля, смена режимов, размеры и прокрутка
  полного сравнения. Save → Undo → Redo побайтно вернули исходник/результат;
  L снова открыл сохранённую форму комнат. Test завершился возвратом в мастерскую.
- Игра: [начало](game-origin.png), [движение внутри](game-inside.png),
  [правый экран](game-right.png), [возврат](game-return.png),
  [низ слева](game-down.png), [низ справа](game-bottom.png),
  [за границей](game-beyond.png). Сравнение центров 128×128 пикселей с палитрой,
  исключая цвета текста 1/7, подтвердило смещения 0/128; **150 пикселей HUD**
  неподвижны. Внутри/после возврата изображение совпало с начальным, за краем —
  с последней комнатой. [Измерения](runtime-frame-match.json).
