# Ограниченный осмотр UX, 2026-10-04

Основание: [issue #2](https://github.com/EriArk/PikoNest/issues/2).
Выводы: [UX_AUDIT](../../UX_AUDIT.md).

- Retroid Pocket Classic, Android 14; установленная версия 0.0.65.
- Скриншот приложения 1240×1080, оригинальный `adb exec-out screencap -p` PNG.
- Репозиторий перед аудитом `0ee9671`; APK не собиралась и не переустанавливалась.
- Управление — ADB key events, не проверка физических кнопок.

Открытие `art.pikoos.runtimelab/.MainActivity` показало
[runtime-unconfirmed.png](runtime-unconfirmed.png): «Игра ждёт», завершение не
подтверждено, A возвращает в PICO-8, B ведёт в лаунчер. R (103) оставил этот экран.
Down (20), A (96) открыли консоль PICO-8 с экранной клавиатурой. Последующие
B (97), Up (19), A (96), затем Select (109) не дали видимого меню обёртки.

Эта последовательность не воспроизводит запуск новой игры из текущего редактора
и не доказывает дефект физической Select. Владелец/происхождение текущего runtime
сеанса и причина ожидания не установлены. Процесс не завершали принудительно,
звук не включали, размеры экрана не меняли. Остальные редакторы в этом осмотре
не пройдены заново; аудит опирается на существующие снимки и исходники.

Проекты/библиотека до осмотра скопированы локально для сравнения. Результат
проверки сохранности — [verification.json](verification.json). Резервные копии,
пользовательские файлы и shared preferences в репозиторий не добавляются.
