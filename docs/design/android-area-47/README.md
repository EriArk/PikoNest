# Android 0.0.47 — проверка площади объекта

2026-10-04, база `154fc14`. Ограниченный M03.2a: обычная Lua-функция
`solid_box(x,y,w,h)` проверяет все тайлы, перекрытые прямоугольником.
Она не перемещает объект и не вводит обязательного героя/сцену/runtime-компонент.

## Управление

Код → A редактировать → X вставить → «Препятствие · область».
Поля задают имя, флаг, размеры карты в клетках и поведение за краем.
Положение и размеры **объекта** передаются аргументами вызова в пикселях карты:
`solid_box(24,40,16,8)`. Это верхний левый угол (24,40), ширина 16, высота 8.
Вызов пока вводится как выражение через существующий редактор; отдельной формы
аргументов пользовательских функций ещё нет. Размер карты не равен размеру объекта.

X из полей либо «Просмотреть Lua» открывает полный код:

- ↑↓ — строка просмотра, ←→ или L/R — листать по шесть строк;
- A — вставить в начало Lua одной правкой, B — вернуться к полям;
- Start не сохраняет и не запускает незавершённое предложение;
- текст переносится по ширине без удаления символов; доступны все строки;
- на touch левая/правая половины кода листают назад/вперёд.

Просмотр, выбранные поля и позиция чтения переживают перезапуск. Смена размеров
экрана пересчитывает переносы; номер видимой строки относится к экранному переносу,
а не к постоянному номеру строки исходника. Короткий preview в форме помечен
«Начало Lua · X весь код». Перед вставкой полной области всегда есть отдельный просмотр.

После вставки остаётся обычный редактируемый Lua. Есть единая отмена в черновике,
а после сохранения — общая история проекта. Обратное открытие всей функции как
настраиваемой механики, пакетное изменение/удаление механик пока не реализованы.

## Семантика и совместимость

Область полуоткрытая: `[x,x+w)` × `[y,y+h)`. Точное касание соседнего тайла
не считается пересечением; минимальное положительное перекрытие уже считается.
Нулевая или отрицательная ширина/высота означает пустую область (`false`).
Проверяются все перекрытые клетки, включая внутренние, а не только четыре угла.
Тайл 0 следует своим флагам. Прозрачность пикселей спрайта здесь не участвует.

«Препятствие» за краем возвращает true, если непустой прямоугольник выходит из
заданного поля. «Свободно» проверяет только пересечение области с полем; полностью
внешняя область возвращает false. Перед сложением координат размеры обрезаются
либо отбрасываются, чтобы избежать переполнения обычных 16.16 чисел PICO-8.
`ceil` применяется до деления на 8, сохраняя перекрытие в `0x0.0001` пикселя.

Сверены [FLR, CEIL, MGET и FGET официального руководства](https://www.lexaloffle.com/dl/docs/pico-8_manual.html).
Границы, камера и округление дополнительно проверены самим официальным runtime.
Инструмент использует обычную карту до 128×64; переназначение памяти карты не
анализируется. Нижняя половина карты использует стандартную общую память gfx/map.
Правила контроля имён — как у [проверки точки](../android-tile-probe-46/README.md),
с дополнительным отказом при переопределении `ceil` или `min`.

Это проверка положения, не непрерывное движение: перенос сразу через стену может
пропустить её. Ограничение шага/пути движения — следующий M03.2b. Нагрузка зависит
от числа перекрытых тайлов; производительность множества больших объектов пока
не профилировалась. Нечисловые аргументы подчиняются обычным ошибкам Lua.

## Проверки и артефакты

Полный `build.ps1` прошёл. Новый `AreaProbeTest` — **27** проверок: вставка,
сохранение прежнего Lua, единая отмена/Redo, просмотр и его сериализация, отказ
повреждённого журнала, конфликты API/имён, контроллер, Start, ошибка сохранения.
Прежние проверки также прошли. Core компилируется JDK без Android.
Вторая сборка содержала только сокращение двух подсказок compact-preview.

Официальный пользовательский PICO-8 0.2.7, Retroid Pocket Classic / Android 14:
