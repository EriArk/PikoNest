## Как читать статус

- **Работает в ограниченном сценарии** — есть код и указанное свидетельство проверки.
- **Частично** — часть пользовательского пути есть, другие обязательные шаги отсутствуют.
- **Не реализовано** — требование/дизайн существует, рабочего общего инструмента нет.
- **Исследование** — даже способ реализации ещё нужно доказать.
- **Принято владельцем** — только явно одобренное направление или проверенный им результат.

Не складываем количество тестов, коммитов и экранов в процент готовности.
Каждая будущая задача закрывается по [правилам приёмки](ACCEPTANCE.md).

## Критические разрывы полного цикла

1. Первый буквальный редактор C01.1 уже позволяет менять обычный Lua в пустом
   проекте. C02.1 добавляет ввод, состояние и цель через каталог; C03.1 даёт общие имена,
   C03.2 — переходы внутри Lua; диагностика и области видимости ещё нужны; полноценный
   путь M1 ещё не принят. Напечатанная строка не считается созданной игрой.
2. Нарисовать спрайт не означает использовать его в игре. Подключение отрисовки,
   событий и поведения требует явного редактируемого кода/известной привязки: G04, M01.
3. Нет инструментов карты, анимации, звука и музыки. Сохранение этих секций
   парсером не считается их редактированием.
4. Запуск связан с подготовленной тестовой оболочкой. Выбор ZIP и удачная проба
   не завершают установку, настройку папок и Splore: R01–R08, P02.
5. Внутреннее атомарное сохранение и разовый экспорт не заменяют постоянную
   историю, внешний проект, резервную копию и полный перенос зависимостей.

## Принятые ограничения планирования

Android сейчас; Linux позже. Обычный `.p8` и официальный runtime остаются основой.
Герой, жанр и шаблон не ограничивают доступ к общим инструментам. Принятая
пиксельная стилистика сохраняется; одобрение её основы не означает приёмку всех
новых экранов. GitHub APK release/prerelease возможен только после явного
подтверждения владельца, что результат полностью устраивает, и разрешения выпуска.
