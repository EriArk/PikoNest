PikoNest beta 2 adds **walls, switch-operated passages and pressure plates** to the handheld game-making workflow.

Create a small game from Blank: draw a moving sprite, paint a wall, connect a plate to a passage and add a goal. Step on the plate, cross, win and restart. This complete journey was authored through the native UI and tested in official PICO-8 on Retroid. Export stays ordinary `.p8` Lua/data.

- Wall/walkable review and independent tile copies.
- Up to 32 linked passage cells, opening when a toggle or plate is On or Off; closing waits for moving objects to leave.
- Plate activator selection, state animation, press sounds and all-switches-on goals.
- Save, Undo/Redo, draft Test and recovery, including older interaction drafts.

**Update in place; do not uninstall.** The package/signature match beta 1. Retroid update preserved all 58 prior project files and five library files byte-for-byte. Your purchased Raspberry Pi ARM64 PICO-8 runtime is still required and is never bundled.

Validated with 94 core suites, focused recovery checks, desktop Lua variants, native Blank/Test/return/save/reopen/export, independent win/restart and a 13-check official-runtime probe. Runtime support and its corresponding-source bundle are unchanged from beta 1.

**Owner confirmation, 11 November:** physical buttons and audible sound work on the Retroid. [Updated device record](https://github.com/EriArk/PikoNest/blob/main/docs/release/beta2/DEVICE_ACCEPTANCE.md#owner-confirmation--11-november-2026). Automated checks used ADB-injected inputs and muted audio; the owner confirmation is separate evidence.

This remains an early beta. Novice usability, broader ergonomics and wider device/provider/launcher checks remain open. Bounded visual recipes do not cover arbitrary Lua or every genre. Android minimum API 26 / interim target 28; tested on Retroid Pocket Classic / Android 14 / PICO-8 0.2.7.
