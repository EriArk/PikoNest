Мастерская

UX-прототип: картридж и запуск демонстрационные. Изменения живут только в макете.

Как пройти сценарий

Поменяйте скорость → посмотрите ту же переменную в коде → нажмите Start → вернитесь. Попробуйте отмену, объяснение и рисование спрайта.

Клавиатура: стрелки — фокус / значение, Enter — выбрать, Esc — назад, Q/E — инструмент, Space — тест, Z — отмена, X — объяснение / палитра. Есть мышь, касание и стандартный Gamepad API.
